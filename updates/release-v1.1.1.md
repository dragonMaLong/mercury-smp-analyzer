# MIP综合分析-DragonScience v1.1.1

## 问题修复

- 修复使用膨胀计常数大于 20 µL/pF 的膨胀计（如 10-0303 为 22.065 µL/pF、10-0820 为 28.63 µL/pF）测得的 SMP 文件导入后曲线显示为一条直线的问题。原因是膨胀计参数识别范围限定为 5–20 µL/pF，超出范围时读取到错误数值，导致高压段数据被丢弃、进汞体积接近 0。识别范围已放宽为 1–100 µL/pF。
- 新增对应的回归测试。

## 验证

- 对本地 70 份 SMP 文件做改前改后对比：67 份结果完全一致；此前显示为直线的 3 份文件（BY-60-70nm、BY-80-90nm、铂源压汞）现在可以正确计算完整的进汞和退汞曲线（约 91–94 个数据点，最高约 33,000 psia）。

## 下载与更新

- GitHub 提供完整单文件 EXE，无需安装 Python。
- Gitee 提供同一 EXE 的 4 个分片；软件内“软件更新”会自动下载、校验并合并。
- 原始 SMP 文件不会被改写。更新前请保存需要导出的结果。
