# MIP综合分析-DragonScience v1.1.0

## 新增与改进

- 新增 Mayer Stowe 和孔结构分析标签，三个分析标签使用独立压力选区。
- Mayer Stowe 增量体积分布和累计体积图使用基于对数粒径的 Akima 样条连接。
- 孔结构累计体积百分比按蓝色选区归一化，拖动边界时实时更新；支持点击压力边界数值直接修改。
- 孔结构默认使用压汞比表面积；右侧显示只读压汞比表面积，单位位于输入框外侧。
- 孔结构汇总表新增压汞比表面积、体积密度和骨架密度，始终显示压汞计算值。
- 改进样品栏列宽、冻结列、数值编辑和批量应用参数；支持表格排序与样品顺序同步。
- 改进跨冻结列框选复制，复制包含列名和样品名；支持样品栏、下方表格整行与曲线的悬停加粗联动。

## 密度校准

- 修正 SMP 温度—汞密度表的记录配对及紧凑 SMP 文件中的温度读取。
- 默认体积密度改用实际起始进汞压力，修正骨架密度和孔隙率的关联偏差。
- 对照 52 份官方报告，51 份三项结果按四位小数完全一致；另 1 份骨架密度在舍入边界处最后一位相差 1。此校准不代表其他孔结构算法均已完全复现。

## 下载与更新

- GitHub 提供完整单文件 EXE，无需安装 Python。
- Gitee 提供同一 EXE 的 4 个分片；软件内“软件更新”会自动下载、校验并合并。
- 原始 SMP 文件不会被改写。更新前请保存需要导出的结果。
